================================================================================
UV PACKAGE MANAGER — SETUP & REFERENCE
================================================================================

uv is a fast Python package and project manager (written in Rust).
It replaces pip, virtualenv, and pip-tools in a single tool.

Environment:
  Python version : 3.13.5
  uv version     : 0.9.24
  uv location    : /Users/paulsampat/.local/bin/uv


--------------------------------------------------------------------------------
FILES CREATED
--------------------------------------------------------------------------------

.python-version
  Tells uv which Python version to use for this project.
  Content: 3.13

pyproject.toml
  The modern Python project config file. Replaces requirements.txt as the
  source of truth for dependencies.

  [project]
  name = "coding-agent"
  version = "0.1.0"
  description = "A coding agent built with Claude API and tool use"
  requires-python = ">=3.13"
  dependencies = [
      "anthropic",
      "python-dotenv",
  ]

uv.lock  (auto-generated by uv sync)
  Pins the exact versions of all dependencies and their transitive
  dependencies. Ensures reproducible installs across machines.
  Should be committed to version control.

.venv/  (auto-generated by uv sync)
  The virtual environment for the project.
  Gitignored — never commit this.


--------------------------------------------------------------------------------
COMMON COMMANDS
--------------------------------------------------------------------------------

  uv sync                    Install all dependencies from pyproject.toml
  uv add <package>           Add a new dependency
  uv add <package> --dev     Add a dev-only dependency (e.g. pytest)
  uv remove <package>        Remove a dependency
  uv run python main.py      Run a script using the uv-managed venv
  uv run pytest              Run tests using the uv-managed venv


--------------------------------------------------------------------------------
REQUIREMENTS.TXT vs PYPROJECT.TOML
--------------------------------------------------------------------------------

  requirements.txt   Old approach. Simple list of packages.
                     Still works with uv (uv pip install -r requirements.txt)
                     but pyproject.toml is the modern standard.

  pyproject.toml     New approach. Declares project metadata AND dependencies.
                     uv reads this as the source of truth.
                     uv.lock is generated from it for reproducible installs.

  Both files exist in this project for reference, but pyproject.toml
  is what uv uses.
